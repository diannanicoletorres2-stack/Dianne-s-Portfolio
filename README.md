# Nicole Torres — Social Media & Content Strategy

Static, GitHub Pages-ready copy of the portfolio site. The page is served from `index.html`; styles and interactions are included inline, and the original image, video, and PDF assets are bundled under `assets/`. No build step is required.

## Publish with GitHub Pages

1. Download the ZIP and **extract it** on your computer. Keep `index.html`, `.nojekyll`, `README.md`, and the `assets/` folder together at the repository root. Do not upload the ZIP itself as the website.
2. Create a new repository on GitHub, then add/publish the extracted project folder using GitHub Desktop (recommended for uploading the full `assets/` folder and its subfolders).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published site URL in the Pages settings.

The site uses relative asset paths, so it works from a GitHub Pages project URL as well as a custom domain.
